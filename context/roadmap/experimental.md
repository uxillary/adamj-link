# Experimental

This document contains ideas that are intentionally exploratory.

Features listed here are not commitments.

They exist to encourage experimentation and creative thinking.

---

## Interface Ideas

- File explorer navigation.
- Interactive operating system elements.
- Modular dashboards.
- Research terminals.
- Dynamic command palette.
- Interactive timelines.
- Ambient technical visualisations.
- Context-aware layouts.
- Optional terminal mode.

---

## Visual Ideas

- Live graphs.
- Real-time counters.
- Repository visualisations.
- System health displays.
- Build progress indicators.
- Activity heatmaps.
- Animated node graphs.
- Data-driven backgrounds.

---

## Interaction Ideas

- Hidden discoveries.
- Progressive disclosure.
- Easter eggs.
- Interactive project relationships.
- Expandable documentation.
- Live activity feeds.
- Keyboard shortcuts.
- Optional advanced mode.

---

## Rule

Experimentation should enhance the experience without compromising clarity, accessibility or performance.

Interesting ideas should earn their place through usefulness, not novelty.
