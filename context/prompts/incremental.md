Read /context before making changes.

Do not redesign or rewrite the site globally.

Use the context only to guide small, incremental improvements.

First inspect the existing implementation and identify the smallest useful change.

Preserve the current structure, content, visual identity, and working systems.

Before editing, summarize:
1. what you found
2. what you plan to change
3. which files you expect to touch

Then make only the agreed scoped change.
