# Human Verification

## Purpose

The contact form includes a lightweight branded verification challenge.

The goal is to reduce automated spam while maintaining a pleasant user experience.

---

## Philosophy

Verification should feel like part of the interface rather than an interruption.

Avoid:

- traditional CAPTCHAs
- difficult puzzles
- frustrating interactions

---

## Principles

Security should support usability.

The experience should remain accessible while discouraging automated abuse.
