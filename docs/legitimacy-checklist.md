# Legitimacy / recategorization checklist

If adamj.link is blocked by network filters, this is usually a category mismatch rather than a malware/adult-content issue.

## Recategorization requests
Submit recategorization reviews to:

- Vodafone Content Control (placeholder: Vodafone reporting channel)
- Webshrinker (placeholder: category dispute form)
- Fortiguard (placeholder: URL category review)
- Cisco Talos (placeholder: URL reputation/category review)
- Symantec / Broadcom (placeholder: site review request)

When submitting, include:
- Domain: `https://adamj.link`
- Category request: `Portfolio / Technology / Business`
- Clarification: site contains no adult content
- Reference page: `https://adamj.link/site-info.html`

## Security/reputation checks

- Run a Google Safe Browsing status check for the domain.
- Confirm TLS certificate validity and no mixed-content warnings.

## Testing approach

- Test over Vodafone mobile data (with Content Control on/off if possible).
- Compare results on a VPN and a non-filtered network.
- Open `https://adamj.link/site-info.html` and legal pages to verify reachability.

## Support note

If blocked, it’s likely ISP filtering; share `/site-info.html` with support teams during recategorization requests.
